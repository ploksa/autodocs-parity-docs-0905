The Fastify Demo is a task management HTTP API built with [Fastify 5](https://fastify.dev), TypeScript, MySQL (via Knex), and cookie-based sessions. It demonstrates the patterns the Fastify community considers best practice: autoloaded plugins, TypeBox schema validation, layered routes, and clear separation between framework, application, and route plugins.

This documentation is generated from the source repository `ploksa/autodocs-parity-source` at commit `1f50cc1`.

## What the application does

Source: [`README.md`](https://github.com/fastify/demo/blob/main/README.md), [`src/routes/api`](https://github.com/fastify/demo/tree/main/src/routes/api)

- Users authenticate with an email and password and receive a session cookie.
- Authenticated users create, read, update, and delete tasks.
- Tasks can be assigned to users, have an image attached, and be exported as a gzipped CSV stream.
- Role-based access control gates destructive and administrative operations (`admin`, `moderator`).
