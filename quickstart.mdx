---
title: "Quickstart: Run the Fastify Demo locally in minutes"
sidebarTitle: "Quickstart"
description: "Install dependencies, start MySQL with Docker Compose, apply migrations, seed data, and run the Fastify demo in dev mode."
---

Follow these steps to get the demo running end to end on your machine. Prerequisites and commands come from [`README.md`](https://github.com/fastify/demo/blob/main/README.md) and [`package.json`](https://github.com/fastify/demo/blob/main/package.json).

<Note>
  You need Node.js 22 or higher, and Docker (for the MySQL container).
</Note>

<Steps>
  <Step title="Install dependencies">
    <CodeGroup>

    ```bash npm
    npm install
    ```

    </CodeGroup>
  </Step>
  <Step title="Create a `.env` file">
    Copy `.env.example` to `.env` and set values. `COOKIE_SECRET` must be at least 32 characters.

    ```bash
    cp .env.example .env
    # then edit .env and set COOKIE_SECRET to a 32+ character secret
    ```

    See [Environment variables](/configuration/environment) for the full list.
  </Step>
  <Step title="Start MySQL with Docker Compose">
    ```bash
    docker compose up -d
    ```

    This starts a `mysql:8.4` container on port `3306` using the credentials from your `.env`. See [`docker-compose.yml`](https://github.com/fastify/demo/blob/main/docker-compose.yml).
  </Step>
  <Step title="Create the database">
    ```bash
    npm run db:create
    ```

    Requires `CAN_CREATE_DATABASE=1` in your environment. Source: [`scripts/create-database.ts`](https://github.com/fastify/demo/blob/main/scripts/create-database.ts).
  </Step>
  <Step title="Run migrations">
    ```bash
    npm run db:migrate
    ```

    Applies all SQL migrations in `migrations/` using Postgrator. See [Migrations and seeding](/database/migrations-and-seeding).
  </Step>
  <Step title="Seed initial data (optional)">
    ```bash
    npm run db:seed
    ```

    Requires `CAN_SEED_DATABASE=1`. Creates three users (`basic`, `moderator`, `admin`), each with a role of the same name. All seeded users share the password `Password123$`. Source: [`scripts/seed-database.ts`](https://github.com/fastify/demo/blob/main/scripts/seed-database.ts).
  </Step>
  <Step title="Start the server in dev mode">
    ```bash
    npm run dev
    ```

    The server listens on `http://localhost:3000` by default. Interactive API docs are served at `http://localhost:3000/api/docs` by [`@fastify/swagger-ui`](https://github.com/fastify/fastify-swagger-ui).
  </Step>
</Steps>

## Log in and call the API

Once seeded, log in with one of the demo accounts:

```bash
curl -i -c cookies.txt -X POST http://localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@example.com","password":"Password123$"}'
```

Reuse the cookie for subsequent requests:

```bash
curl -b cookies.txt http://localhost:3000/api/tasks
```
